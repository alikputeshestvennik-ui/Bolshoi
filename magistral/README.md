# Магистраль

Транспортная экономическая стратегия: железная дорога и авиация, от одного города до всего мира.

APK собирается автоматически при каждом изменении в ветке `main`. Готовый файл лежит в разделе **Releases**.

Игра целиком находится в `app/src/main/assets/index.html`. 3D-библиотека three.js подкладывается при сборке, поэтому приложение работает без интернета.
