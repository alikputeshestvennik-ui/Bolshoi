# Фоновый исполнитель Codex для Тени

GitHub Actions запускает OpenAI Agents SDK и Codex app-server под выбранной моделью без отдельного окна. Android шифрует цель и ключ выбранного провайдера AES-GCM до отправки в workflow; результат также шифруется перед сохранением артефакта. Ключ шифрования выводится из GH_PAT, доступного приложению и workflow как секрет. Не публикуйте APK с вшитым GH_PAT или другими ключами: их можно извлечь из приложения.

Требования: секреты репозитория GH_PAT и DEEPSEEK_API (или ANYMODEL_KEY); GH_PAT должен разрешать запуск и чтение Actions и чтение артефактов в этом репозитории. Раннеру нужны Python, Node.js, Codex CLI и работающая песочница Linux. Данные задачи не записываются в открытом виде в inputs или артефакты, но загружаемые сторонние зависимости и доверенная инфраструктура GitHub имеют доступ к секретам во время выполнения. Задача не имеет доступа к телефону и его файлам. Поддерживаются DeepSeek, AnyModel, ChatGPT и заданный пользователем публичный HTTPS Responses API. Локальные и частные IP-адреса отвергаются.

Codex использует Responses API с инструментами. Обычная совместимость только с Chat Completions недостаточна. Песочница workspace-write ограничивает команды рабочим каталогом, сеть команд по умолчанию выключена. Очереди и лимиты GitHub Actions, доступность модели и баланс провайдера влияют на работу; нужно дождаться подтверждения окончания задания.
