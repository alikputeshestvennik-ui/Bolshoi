# Согласованное обновление интерфейса

- Убрана верхняя шапка чата; системная строка прозрачная, ленты плавно уходят под верхний край.
- Восстановлена нижняя панель: чат, история и важное, задачи, настройки. Ввод доступен на основных экранах.
- Модель и глубина размышлений показываются при фокусе в поле сообщения и открытой клавиатуре.
- В истории видны все записи, включая фоновые, а нажатие открывает экран задачи. «Важное» — отдельная вкладка истории.
- Экран задачи использует согласованную палитру кабины; пустой список задач имеет явное состояние.
- Настройки сгруппированы по назначению. Существующие функции сохранены; город и денежный лимит имеют отдельные страницы.
- При подключении ChatGPT в списках отображаются его модели. Сторонние модели можно включить в настройках; уже выбранные модели не изменяются автоматически.
- Исправление восстановления сессии Telegram сохранено.

Подписанный APK этой ветки публикуется как артефакт сборки GitHub, без замены общего релиза. Автоматические проверки GitHub Actions для этой ветки не запускаются по просьбе владельца. Установку поверх текущей версии и работу на устройстве проверяет владелец.
