# Обновление интерфейса Тени

База изменений: `codex/chatgpt-signin` (`cb8d5a7`). Ветка содержит новые функции
из `agent-v1`, которых ещё нет в `main`. Поэтому PR с интерфейсом направлен в
`codex/chatgpt-signin`: перенос всей этой версии в `main` — отдельное решение.

## Что изменено

- Компактное подписанное меню вместо нижней панели с четырьмя иконками.
- Поле ввода принадлежит только чату. На остальных страницах доступна вся высота.
- Общая шапка без аватара и большой обводки; вложенные страницы имеют кнопку назад.
- Чат: больше воздуха, широкие читаемые ответы, заметные действия поиска и выбора
  модели. Файлы, голос, выделение, пересылка и подтверждения сохранены.
- История: общий расход токенов с учётом фоновых записей,
  токены в карточках, группировке моделей и графике. Нулевые старые записи
  подписаны как отсутствие данных, а не как нулевая стоимость.
- Важное: только важные события, без счётчиков уведомлений и итогов дня.
  В историю добавлена ссылка на важное. Окончательное объединение страниц
  оставлено для согласования.
- Telegram запускает восстановление сессии при возвращении в приложение независимо
  от настройки сводки. Открытие настроек не создаёт второй клиент TDLib.
  Непроверенное подключение, восстановление, запрос входа и ошибка различаются.

## Проверка настроек

Все функции сохранены. Удаление или объединение требует согласования с владельцем.

| Пункт | Результат проверки |
| --- | --- |
| Что Тень помнит | Оставлен: просмотр, подтверждение и удаление памяти |
| Сам пишет первым | Оставлен: самостоятельные сообщения и расписание; пересечение с «Поведением» стоит объединить после согласования |
| Отвечать за меня | Оставлен: отдельные правила и ограничения автоответов |
| Оформление | Оставлены темы, обои и автоматическая смена; новые общие компоненты используют выбранную палитру |
| Быстрый доступ | Оставлены интеграции выделения, меню «Поделиться», плитка и цифровой помощник |
| Поведение | Оставлены вибро, голосовые сигналы, вспышки, пробуждение и сводка Telegram; предлагается перенести их в «Уведомления и инициативу» |
| Голос | Оставлены озвучка, выбор движков и голосов: это отдельные функции |
| Мониторинг | Оставлены интервал, фоновая работа, время итога и YouTube; экран итога удалён, но его фоновая генерация пока сохранена |
| ChatGPT | Оставлены вход, список моделей и выход |
| Почта Gmail | Оставлены оба ящика, смена паролей и проверка подключения |
| ЮMoney | Оставлен: используется отдельным инструментом платежей |
| Telegram | Исправлены запуск и отображение статуса; формы входа видны сразу |
| Яндекс Музыка | Оставлена: используется инструментами поиска и воспроизведения |
| YouTube | Оставлен: подписки, плейлисты и подборки |
| Город и лимит | Предлагается разделить: город относится к погоде, лимит — к использованию платных провайдеров |
| Разрешения | Оставлены: каждое разрешение имеет действующий потребитель |
| Для разработчика | Переименован в «Модели и использование»: обычному пользователю тоже нужны роли моделей, проверка задач и тест подключения |

Решения для согласования:

1. Объединить «Важное» и «Историю» в одну страницу с двумя вкладками.
2. Объединить сигналы из «Поведения» и настройки «Сам пишет первым».
3. Отключать ли саму фоновую генерацию итога дня вместе с удалённым экраном.
4. Разделить город и денежный лимит, сохранив лимит для платных провайдеров.

## Приёмка на устройстве

1. Открыть все разделы через верхнее меню и вернуться в чат.
2. Проверить клавиатуру, голосовую запись, отмену, вложение и выделение сообщения.
   Перейти в историю и обратно: черновик сообщения должен сохраниться.
3. Сверить расход токенов за день, 7 дней и текущий месяц. Скрытие фоновых карточек
   не должно менять общую сумму за период.
4. Проверить длинные ответы, увеличенный системный шрифт и альбомную ориентацию.
5. Открыть важное без событий и с событиями из нескольких источников.
6. Пройти все пункты настроек, в том числе вложенные экраны подключений.
7. Войти в Telegram, закрыть процесс и открыть Тень при выключенной сводке Telegram:
   сначала восстановление, затем подключённый аккаунт без повторного кода.
8. Установить обновление с той же подписью поверх приложения и повторить пункт 7.
   Полное удаление приложения удаляет его закрытые данные и требует повторного входа.

CI собирает debug APK приложения и лаунчера, запускает тесты идентификации
и UI-проверки. Снимки тестовых экранов и отчёт тестов сохраняются как `ui-checks`.
Подписанная сборка для установки поверх текущей версии сохраняется как
`agent-release-apk` в workflow Build Agent APK. У неё та же конфигурация подписи,
что у обычных обновлений. Сборки этой ветки не заменяют публичный релиз `ten-latest`.
