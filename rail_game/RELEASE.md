# Перегон · Долина сосен

Железнодорожная 3D-игра: детализированный дизельный состав, три станции, две ветки, мосты, лес и грузовой терминал.

**PEREGON.apk** — подписанная игра для Android 8+ с актуальным Android System WebView. **PEREGON-presentation.pdf** — 5 слайдов с реальными кадрами.

Управляй тягой и тормозом, выбирай ветку, точно останавливайся у платформ. Шесть заданий и свободная поездка. Вращение камеры, вид из кабины, смена освещения, гудок и звук двигателя. Горизонтальный экран, полная работа офлайн.

Сборка, Android lint, проверка подписи и тесты физики/WebGL выполнены в GitHub Actions. Физический Android-телефон пока не тестировался. Это игра с упрощённой физикой, один состав и одна долина.
