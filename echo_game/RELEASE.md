Самостоятельная офлайн-аркада для Android 8+: защити последний маяк в восьми секторах космоса.

**Скачать:** `ECHO.apk` — игра; `ECHO-presentation.pdf` — презентация с кадрами из игры.

Веди корабль пальцем: он стреляет автоматически. Собирай энергию, выпускай ЭХО и выбирай улучшения между секторами. Игра устанавливается отдельно от «Тени», без рекламы, покупок и аккаунтов. Звук можно включить в верхнем углу.

APK собран и подписан в GitHub Actions существующим ключом репозитория. CI запускает браузерные проверки игровых механик и Android lint. На физическом Android-устройстве игра пока не проверена.
