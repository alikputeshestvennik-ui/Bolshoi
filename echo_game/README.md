# ЭХО · Последний маяк

Самостоятельная офлайн-игра для Android 8+. Восемь секторов, автоматическая стрельба, защита маяка, собираемая энергия, ударная волна, выбор улучшений и финальный противник. Собственный Canvas 2D движок внутри Android WebView, без сетевых запросов, рекламы, аккаунтов и сторонних игровых ресурсов. Процедурная графика и синтезированный звук.

## Управление
- Веди корабль пальцем по игровому полю. Стрельба автоматическая.
- Подбирай зелёные частицы для подзарядки.
- Нажми ЭХО при полном заряде: волна поражает всех врагов и отбрасывает выживших.
- Защищай центральный маяк. Между секторами выбери один модуль.
- Звук включается кнопкой ♫. Пауза — Ⅱ или Android Back; сворачивание также ставит игру на паузу.
- В браузере работают WASD/стрелки, пробел и Escape.

## Структура
- `app/src/main/assets/`: автономная игра, её же можно открыть в браузере через HTTP.
- `app/src/main/java/`: Android-оболочка без разрешения INTERNET.
- `qa/`: браузерные проверки механики, ввода, паузы и сохранения; снимки экрана.
- `presentation/`: презентация; PDF генерируется в CI по настоящим снимкам игры.

## Сборка
Workflow `.github/workflows/ECHO_GAME.yml` запускает браузерные тесты, создаёт презентацию PDF и собирает подписанный release APK. Использует существующие ANDROID_KEYSTORE_B64 / ANDROID_STORE_PASSWORD / ANDROID_KEY_PASSWORD / ANDROID_KEY_ALIAS. Сервисные ключи игре не требуются. App ID `ru.alim.echo`: устанавливается отдельно от Тени.

Артефакт `echo-delivery` содержит `ECHO.apk`, `ECHO-presentation.pdf`, снимки и отчёт тестов. Отдельный GitHub Release публикуется с уникальным тегом `echo-v1-<номер сборки>`.

## Проверки и границы
Браузерные тесты проверяют реальные столкновения, накопление/расход заряда, переходы секторов, поражение, победу, сохранение рекорда и управление. APK собирается и проверяется Android lint в GitHub Actions. Проверку физического телефона и Android WebView следует отличать от этих автоматических проверок.
