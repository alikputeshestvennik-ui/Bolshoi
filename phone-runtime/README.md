# Codex на телефоне

Запуск из Linux-окружения телефона: `sh phone-runtime/start.sh`.
Используется тот же режим, что в установленном Android-клиенте Codex:
команды имеют доступ к Linux-окружению; отдельной внутренней песочницы нет.
Сервис слушает только 127.0.0.1:8766 и требует ключ из ~/.ten-local/token.
Введите этот ключ в настройках «Тени». Не публикуйте его.

Рабочие файлы: ~/.ten-local/workspace. Для DeepSeek и AnyModel задайте ключи
в настройках приложения и выберите модель в чате Codex. Используется Responses API;
работоспособность конкретного провайдера требует проверки с действующим ключом.
ChatGPT использует авторизацию установленного Codex.

Окружение должно оставаться запущенным. Текущая версия принимает только текст;
нет кнопки отмены, восстановления запроса после закрытия приложения и выдачи
файлов вложениями. Это тестовая сборка, не законченный полноценный клиент.

Тесты: python3 -m unittest discover -s phone-runtime -v
