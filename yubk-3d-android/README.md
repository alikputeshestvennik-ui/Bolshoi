# ЮБК · 3D Android

Офлайн 3D-приложение по Южному берегу Крыма: Севастополь — Балаклава — Форос — Алупка — Ялта — Гурзуф — Алушта. Android 6+, Java, OpenGL ES. Сетевые разрешения и ключи API не нужны.

## Что работает в 0.6.0

Стартовый экран — графическая карта всего ЮБК с рельефом, морем, населёнными пунктами и выделенным Южнобережным шоссе. Маршрут разбит на 21 участок примерно по 6 км. Касание линии шоссе выбирает ближайшую точку, показывает километр от Севастополя и открывает подтверждение перехода.

В режиме прогулки загружается только текущий участок. Это региональная потоковая схема, а не одна гигантская сцена: телефон не обязан держать в памяти все 121 км одновременно. При приближении к краю участка приложение переключает соседний тайл и сохраняет положение на маршруте. Модель содержит рельеф, дорожное полотно, обочины, тротуары, разметку, отбойники, подпорные стены, здания, окна, реки и придорожную растительность.

Кнопка «Улицы» открывает список улиц городов ЮБК с телепортом в выбранную точку: загружается нужный участок, и камера становится посреди улицы. На региональной карте дополнительно отрисованы улицы и водоёмы.

Интерфейс собран из графических карточек и Canvas-кнопок: иконки маршрута, места, автомобиля, скорости и карты. Стандартные Android-кнопки не используются для основных действий. На экране прогулки есть мини-карта, текущий участок, километр маршрута и ближайшее место.

Скоростные режимы переключаются кнопкой скорости: `5 м/с` для осмотра, `40 км/ч` для городского движения и `70 км/ч` для проезда по шоссе. Нажатие кнопки скорости циклически меняет режим и сразу применяет его к сцене.

## Данные

Геометрия дорог, зданий, рек, водоёмов, береговой линии и населённых пунктов — OpenStreetMap. Высоты — Mapzen/Tilezen Skadi (SRTM). Генератор прореживает данные в коридор вокруг маршрута (520 м), поэтому сцена остаётся мобильной; дорожное полотно детализируется сильнее, чем остальной ландшафт. Региональная карта — `app/src/main/assets/route/region_map.png`; тайлы и метаданные — в той же папке.

Воспроизведение:

```sh
python3 tools/prepare_terrain.py
python3 tools/prepare_route.py
python3 tools/validate_route.py
```

Проверка покрытия, размеров мешей, конечности координат и допустимости цветов запускается в GitHub Actions.

## Ограничения

Рельеф построен по DEM с шагом около 25 м. Это не геодезическая съёмка и не гарантирует точность бордюров, выемок и подпорных стен. Контуры и этажность зданий взяты из OSM; фасады, окна, большинство деревьев, разметка и цвета декоративные, а не фотографии реальных объектов. Мосты и тоннели представлены упрощённо. Автомобилей, пешеходов, звука и спутниковых текстур пока нет. Координаты относятся к виртуальной камере, не к GPS телефона.

## Сборка и подпись

В репозитории Bolshoi откройте Actions → **Build YUBK 3D APK**. Workflow собирает debug APK для эмуляторного теста и подписанный release APK. Для release используются secrets `ANDROID_KEYSTORE_B64`, `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_PASSWORD` и `ANDROID_KEY_ALIAS`.

Итоговые артефакты:

- `yubk-3d-debug-apk` — тестовая сборка;
- `yubk-3d-signed-apk` — подписанный `app-release.apk`;
- `yubk-device-test-reports` — отчёт и скриншоты эмулятора.

Локально нужны JDK 17, Android SDK 35 и Gradle 8.9. Для проверки Java без Gradle можно использовать `javac` с `android.jar`; эмуляторные тесты выполняются в Actions.
