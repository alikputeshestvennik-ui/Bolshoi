# ЮБК · 3D Android

Самостоятельное офлайн Android-приложение: цифровой рельеф от Севастополя до Алушты, вращение одним пальцем, масштаб двумя пальцами, сброс вида. Android 6+; Java и OpenGL ES, без ключей API и сетевых разрешений.

## Геометрия

Область 33.35–34.50° E, 44.35–44.75° N. Реальные высоты Mapzen/Tilezen Skadi (SRTM и другие источники), сетка 321 × 181, шаг около 250–290 м. Оси переведены в метры через радиусы кривизны WGS84 при 44.55° N; вертикальный коэффициент 1. Локальная равнопромежуточная проекция имеет погрешность горизонтального масштаба менее 0.4% в этой области. Это обзорный рельеф, не геодезическая модель. Высоты относительно уровня моря; отрицательные значения обрезаны до 0. Синий цвет отмечает нулевые высоты, а не точную векторную береговую линию. Здания, спутниковая текстура, батиметрия и подписи городов пока не включены.

## Сборка

Откройте эту папку в Android Studio. Нужны JDK 17, Android SDK 35 и Gradle 8.9. Выполните `gradle :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Исходная сетка уже включена в assets. Для воспроизведения: `python3 tools/prepare_terrain.py` (интернет нужен только для скачивания исходных DEM). Метаданные и SHA-256: `app/src/main/assets/terrain.json`.
