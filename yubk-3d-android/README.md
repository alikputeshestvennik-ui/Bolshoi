# ЮБК · 3D Android

Офлайн Android-приложение с обзорным рельефом Севастополь — Алушта и пилотным режимом прогулки по району Ялты. Android 6+, Java, OpenGL ES. Ключи API и сетевые разрешения не нужны.

## Карта и прогулка (0.4.0)

Стартовый экран — карта пилотного района Ялты с названиями улиц. Масштабирование двумя пальцами (1–16×), перемещение одним пальцем. Подписи скрываются при пересечении и появляются по мере приближения. Тап выбирает точку на ближайшей доступной дороге в радиусе 100 м, показывает маркер и подтверждение с названием улицы и координатами. «Отмена» оставляет на карте. Жесты панорамирования и pinch не вызывают телепорт.

«Улицы» открывает 52 названия с тем же подтверждением перехода. «Весь район» сбрасывает масштаб, «Продолжить» возвращает в предыдущую прогулку. Из прогулки кнопка «Карта» или нажатие на мини-карту возвращают к выбору места, не сбрасывая положение карты. Обзор всего побережья убран из основного сценария: сейчас работаем внутри пилотного контура.

Скорость по умолчанию 5 м/с; доступны 3, 5 и 8 м/с. Это ускоренное перемещение для осмотра модели, а не физическая скорость обычной ходьбы. Проверки столкновений выполняются короткими шагами. Координаты относятся к камере, не GPS телефона.

Окна вынесены в отдельные группы по 80 м: удалены внутренние дубликаты, наружные поверхности отнесены от стены, применён depth bias. Мелкие окна отображаются только для групп ближе 180 м. Предпочтителен 24-битный буфер глубины, на старых устройствах используется 16-битный. Число вершин сокращено с 785370 до 569634. Улучшение FPS зависит от устройства; замер на физическом телефоне пока не выполнен.

GitHub Actions выполняет сборку, Lint, проверки геоданных и тест сценария карта → подтверждение/отмена → прогулка на Android-эмуляторе. Скриншоты и отчёт — артефакт `yubk-device-test-reports`.

Обновление навигации: `python3 tools/prepare_navigation.py` после подготовки сцены. Проверка: `python3 tools/validate_navigation.py`.

## Прогулка по Ялте

Подтверждение выбранной на карте точки переносит камеру на улицу. Поворот взгляда — пальцем по сцене, ходьба — удержанием кнопок «Вперёд» / «Назад». Кнопка «Карта» возвращает к выбору точки. Есть ограничения движения у зданий, моря и границ сцены; это просмотрщик, не навигатор.

Пилот: 34.145–34.165° E, 44.487–44.497° N, около 1.6 × 1.1 км. Включены 1408 зданий, 2873 отрезка дорог и дорожек, одно дерево из OSM и 266 условных деревьев. Сетка поверхности 81 × 61, около 20 м; это интерполяция исходного DEM, а не новая съёмка с точностью 20 м. Сцена содержит 569634 вершины и занимает около 15 МБ в буфере отображения.

Контуры зданий и оси дорог — OpenStreetMap. Высоты зданий берутся из height/building:levels, при отсутствии — 9 м. Ширина дороги — из width либо условная по классу. Цвета, окна, разметка и большинство деревьев — декоративные. Фасады не являются фотографиями реальных домов. Тоннели и мосты в пилоте пропущены; здания со сложными multipolygon-контурами не импортируются. Рельеф DEM не передаёт точно бордюры, подпорные стены и дорожные выемки. Деревья исключены из проезжей части и контуров зданий, но не имеют физической коллизии. Звука, автомобилей и спутниковой текстуры пока нет.

## Общий рельеф

Область 33.35–34.50° E, 44.35–44.75° N. Реальные высоты Mapzen/Tilezen Skadi, сетка 321 × 181, шаг около 250–290 м. Оси в метрах, вертикальный коэффициент 1. Локальная проекция WGS84 с опорной широтой 44.55°; погрешность горизонтального масштаба менее 0.4%. Отрицательные высоты обрезаны до нуля. Синий цвет нулевых высот — приближение моря, не точная береговая линия. Это обзорная визуализация, не геодезическая модель.

## APK и сборка

В репозитории Bolshoi откройте Actions → **Build YUBK 3D APK**. Успешный запуск публикует артефакт `yubk-3d-debug-apk`. Это тестовый APK, не релиз магазина. Workflow изолирован от сборки agent_android.

Локально: откройте эту папку в Android Studio. Нужны JDK 17, SDK 35 и Gradle 8.9. Выполните `gradle :app:assembleDebug :app:lintDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Данные уже включены. Воспроизведение:

```sh
python3 tools/prepare_terrain.py
python3 tools/prepare_walk.py
python3 tools/validate_walk.py
```

Для точного воспроизведения OSM-среза сначала распакуйте `data/yalta.osm.gz` в `.cache/yalta.osm`. Иначе prepare_walk скачает актуальные данные OSM и результат может отличаться. Данные высот загружаются с AWS при отсутствии локального кэша.

## Следующий уровень качества

Сначала проверить пилот на телефоне: плавность, расход памяти, движение вдоль дорог. Далее: пространственное разбиение и уровни детализации, затем точные дороги и подпорные стены, индивидуальные фасады по лицензированной съёмке. После проверки этого участка расширять покрытие вдоль побережья. Фотореализм требует более точных исходных данных; текущая сцена — географически привязанный прототип.
